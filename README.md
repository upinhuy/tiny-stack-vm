A tiny stack virtual machine for make.fun's tiny stack ISA (v1). One Node 22
program, `main.ts`, answers all 40 instances of a set: 32-bit wrapping
arithmetic, a 256-value stack, branches, calls, 256 words of memory, I/O, and
all ten traps with their own exit codes.

Try make.fun: https://make.fun/r/hv9zk8y5
